# 画面と表示設定

## 主な画面

- ダッシュボード
- 番組表
- 番組検索
- 予約一覧と時刻指定予約
- 録画中
- 録画済み一覧・詳細・視聴・アップロード
- 自動予約ルール
- 放送中番組とライブ視聴
- エンコード
- ストレージ
- 設定

モバイルでは主要画面をボトムバーへ配置し、それ以外を「その他」へまとめます。
デスクトップではサイドナビゲーションを使用します。

## PWA

iOSとAndroidのホーム画面へ追加し、ブラウザUIのないstandalone表示で利用できます。
配信元はHTTPS、またはブラウザが安全なoriginとして扱うlocalhostである必要があります。

## 表示設定

次の設定はブラウザの`localStorage`へ保存します。backendのサーバー設定は変更しません。

- ライト・ダーク・OS連動テーマ
- アクセントカラー
- すりガラスの透過と無効化
- 半角表示
- 番組表の表示時間、列幅、縦倍率、描画方式
- 番組表の放送局ロゴとジャンル強調
- 一覧の表示件数
- ドロップ情報
- ボトムバーの項目と並び順

設定はブラウザprofile・端末ごとに独立します。

## 状態表示

データを取得する画面には、読み込み中、再読み込み中、取得エラー、0件の状態を用意しています。
取得エラー時は再試行でき、バックグラウンド更新中は現在の表示を維持します。
